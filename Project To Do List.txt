MODULE B-4: Grammar Check (LanguageTool Docker)
  [✔️] Docker command: docker run -d -p 8010:8010 silviof/docker-languagetool
  [✔️] LANGUAGETOOL_URL=http://localhost:8010 in .env
  [✔️] check_grammar(text) → HTTP POST to LanguageTool
  [✔️] Parse errors: message, context, suggestions, type
  [✔️] grammar_score = max(0, 10 - errors/word_count*100)
  [✔️] Return: total_errors, errors[], grammar_score

MODULE B-5: Plagiarism Check (Custom TF-IDF)
  [✔️] install: scikit-learn, numpy
  [✔️] preprocess_text(): lowercase, remove punctuation
  [✔️] calculate_similarity(text1, text2) → cosine similarity (0-1)
  [✔️] check_plagiarism(new_text, assignment_id):
        fetch all DB texts → compare → return matches
  [✔️] Result: is_plagiarized (>0.7), similarity_score, matched_ids
  [✔️] Exclude self from comparison

MODULE B-6: Content Quality (Llama 2 via Ollama)
  [✔️] Install Ollama, pull llama2: ollama pull llama2
  [✔️] LLAMA_URL=http://localhost:11434 in .env
  [✔️] analyze_content(text, subject) → POST to Ollama API
  [✔️] Prompt: "Evaluate this assignment. Return JSON only:
       {relevance, structure, depth, clarity} scores 0-10,
       strengths[], improvements[], summary"
  [✔️] Parse JSON response safely (try/except)
  [✔️] Truncate text to 2000 words before sending

MODULE B-7: Checker Orchestrator & Results
  [✔️] check_assignment(assignment_id):
        asyncio.gather → grammar + plagiarism + content parallel
  [✔️] final_score = grammar*0.30 + content*0.50 + plagiarism*0.20
  [✔️] If plagiarized → final_score = 0
  [✔️] grade: A(9+), B(7+), C(5+), D(3+), F(<3)
  [✔️] Save to "results" collection
  [✔️] POST /api/checker/check/{assignment_id}
  [✔️] GET  /api/checker/result/{assignment_id}
